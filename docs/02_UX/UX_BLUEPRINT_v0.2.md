# ARGUS SHOGUN — UX BLUEPRINT v0.2

Status: **LOCK dla vertical slice**

## Zasada

Minimum czytania, maksimum orientacji. Telefon jest podstawowym ekranem.

## DZISIAJ

1. data + dzień cyklu,
2. krótki status,
3. jedna karta donicy wymagającej uwagi, jeśli istnieje,
4. jedna duża karta `Plan na dziś`.

## PLAN

- trzy karty bazowe,
- maksymalnie układ 2×2,
- jedna etykieta `ARGUS poleca`,
- szybkie różnice,
- `Dlaczego taki plan?` na żądanie,
- wybór planu nie wymaga osobnego ekranu zatwierdzania.

## PRZYGOTOWANIE

- produkt,
- ilość,
- dobrane narzędzie,
- bez obowiązkowego checklistowania,
- ostrzeżenia są informacją, nie bramką.

## MIXER

Każdy krok:

1. składnik i ilość,
2. `DODAJ`,
3. `START MIESZANIA`,
4. timer,
5. sygnał końca,
6. `NASTĘPNY`.

Operator ma dostęp do `POMIŃ TIMER` i może przejść dalej bez domenowego gate'a.

## DONICE

D1–D4 osobno:

- szybki wpis masy,
- ostatnia masa,
- zmiana względem poprzedniej,
- historia pomiarów.

## HISTORIA

Pokazuje wykonane operacje: czas, wariant, objętość, tryb kontroli i składniki zapisane w momencie wykonania.

## TRENDY

V1:

- masa D1–D4 w czasie,
- liczba wykonanych sesji,
- użyte warianty.

Bez analityki udającej wiedzę, której system nie ma.
